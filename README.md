# 肩背教练

一个只给自己用的安卓离线训练 App（PWA）。六周肩背优先计划、16 个 Canvas 关节骨架动作动画、结构化动作教学、跟练计时与本地训练记录。原生 HTML/CSS/JS，无框架、无构建步骤、无 CDN、无在线字体或图片依赖。

线上地址：<https://14866312.github.io/shoulder-back-coach/>

## 安卓 Chrome 安装到主屏幕

1. 用安卓 Chrome 打开 <https://14866312.github.io/shoulder-back-coach/>，等页面完整加载一次。
2. 点右上角 `⋮` → **添加到主屏幕** / **安装应用**。
3. 回到桌面点「肩背」图标，以独立窗口打开；首次联网加载后即可断网使用。

## 离线与数据

- Service Worker 会预缓存页面、脚本、样式、图标。断网后仍可打开四个页签、看动画、跟练和记录。
- 训练数据只保存在当前手机的 `localStorage`（键名 `shoulderBackCoach.v1`），不上传、无账号、无服务器。
- 换手机、清理浏览器数据或卸载前，请在「设置 → 数据」导出 JSON 备份。导入会整体替换现有数据，界面会先提示确认。
- 备份文件名格式：`肩背教练-备份-YYYYMMDD.json`。

## 页面与使用

- **今天**：日期、周次、阶段、当天主题、计划组数、预计时长、开始训练；休息日显示下次训练。第 3 周起出现「本周恢复确认」，三项都勾选才进入完整组数；也可选本周减量。
- **计划**：周一/周二/周四/周五四张日卡，默认折叠。点动作可看正确/错误动画、要点和常见错误。
- **记录**：按日期倒序查看训练；按「训练日 + 动作」筛选历史与上次摘要；可删除单次记录（二次确认），可导出/导入备份。
- **设置**：起始日期（只能选周一）、周五臀桥类型、体重（可选，用于蛋白质 1.6–2.0 g/kg/天估算）。
- **跟练**：动作进度、组数、已用时间、16:10 动画、正确/错误切换、上次记录、重量/次数/RIR、组间倒计时（-15 秒 / +15 秒 / 跳过）、关节不适跳过、中途保存退出与继续。

## 阶段与进阶

- 第 1–2 周：所有动作 2 组，RIR 约 3。
- 第 3 周起：三项恢复确认后进入完整组数；任一项未确认保持 2 组。
- 本周减量：组数减半向上取整（3→2，2→1），RIR 3–4；可与完整互相修改。
- 第 6 周结束后进入复盘，可「开始下一轮」：起始日设为本周一，清空每周确认，保留历史记录。
- 双进阶只比较「同一训练日 + 同一动作 + 同一器械设置 + 相同重量」。同一重量连续两次全部达标，提示加最小一档；加重后低于次数下限，提示退回上一次重量。适应期与完整期不混算。
- 自重动作不建议加重；自重臀桥连续两次所有组达到 20 次，会提示可加少量负重。

## 四天计划摘要

| 训练日 | 主题 | 完整阶段 | 适应期 |
|---|---|---:|---:|
| 周一 | 上肢A · 背宽优先 | 14 组 | 12 组 |
| 周二 | 下肢A · 手臂 | 11 组 | 10 组 |
| 周四 | 上肢B · 肩宽优先 | 14 组 | 12 组 |
| 周五 | 下肢B＋手臂＋核心 | 12 组 | 12 组 |
| 合计 |  | 51 组/周 | 46 组/周 |

- 周一：高位下拉 3、胸支撑器械划船 2、直臂下压 2、哑铃侧平举 3、反向蝴蝶机 2、哑铃平板卧推 2。
- 周二：腿举 3、坐姿腿弯举 2、哑铃站姿提踵 2、绳索下压 2、哑铃弯举 2。
- 周四：胸支撑器械划船 3、高位下拉 2、哑铃侧平举 3、绳索侧平举 2、反向蝴蝶机 2、哑铃平板卧推 2。
- 周五：腿举 2、坐姿腿弯举 2、臀桥机 2（或自重臀桥 2）、绳索下压 2、哑铃弯举 2、卷腹 2。

配比按「背宽 + 肩宽」重排：背 12 组（下拉/划船/直臂下压）、侧平举 8 组（哑铃 + 绳索）、后束 4 组、胸 4 组；腿部从 12 组压到 11 组，排在肩背之后不再抢恢复。坐姿器械肩推已从计划里移出（动作定义和教学仍保留，需要时把 id 加回 `DAYS.thu.exercises` 即可）。

只保留不依赖固定器械的动作：推胸用哑铃平板卧推，提踵用哑铃站姿提踵（踩台阶/踏板）。核心只有周五的卷腹，周二不再安排核心动作；旧记录里的上斜器械推胸、器械提踵、死虫式仍能正常显示名称。

哑铃记每只重量；器械记同一设备标示重量；自重动作填 0；单侧动作记每侧次数。

## 16 个动作动画与教学

高位下拉、胸支撑器械划船、直臂下压、哑铃平板卧推、哑铃侧平举、绳索侧平举、反向蝴蝶机、坐姿器械肩推、腿举、坐姿腿弯举、哑铃站姿提踵、绳索下压、哑铃弯举、自重臀桥、臀桥机、卷腹。

动画用固定的关节骨架（上臂 67 / 前臂 61 / 大腿 108 / 小腿 100 / 躯干 122 px），手锁在器械握把、脚锁在踏板或地面，肘与膝由两骨 IK 反解，器械（踏板、钢索、配重、髋垫）由同一份 pose 反推，所以接触点不会漂。每个动作有 3 个具名错误变体，错误画面叠加橙色正确残影 + 红色标注。

每个动作配 5 块结构化教学（`guides.js`）：器械设置、分步动作、常见错误、自检与安全、器械差异；常见错误逐条给出「现象 / 为什么错 / 怎么改 / 自检」。

## 教学内容的折叠层级

- **详情页**：4 个同级折叠（器械设置 / 分步动作 / 常见错误 / 自检与安全），默认全关，右上角「全部展开」一键开全部；顶部常驻一句要点。切到「错误示范」时出现 3 个错误胶囊，点哪个就播哪个变体。
- **跟练页**：1 个总折叠「动作教学 · 4 项」，默认关；上方常驻一句要点 + 2 条关键提示，展开后是四段一句话摘要。


## 已知限制

- 器械配重刻度因健身房设备而异，App 只提示「加最小一档」，不计算统一公斤数。
- 目前只按安卓 Chrome 实测；iOS Safari 未测试。
- 清除浏览器网站数据会同时清除训练记录，请定期导出备份。
- 计划是训练框架，不替代医疗建议；关节刺痛、卡痛或放射痛应停止诱发动作并评估。
